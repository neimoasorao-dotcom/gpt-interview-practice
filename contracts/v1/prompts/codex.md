# Web開発専用Codexへ渡す完成プロンプト v1.0.0

あなたは、このリポジトリで英検準1級Voice面接練習の「記録・分析Webアプリ」を実装する開発担当です。私は面接練習を別のChat/Voice、方針決定を別のWorkで行います。このCodexでは面接官や採点者にならず、採点尺度・分類・データ仕様を独自変更しないでください。

添付の01-system-design.md、02-rubric.md、03-codex-development.md、schemas、profiles、examples、validation、release-manifest.jsonを先に読んでください。01文書の①〜⑤を踏まえた確定した実装対象として扱います。矛盾があれば具体例・影響・最小修正案を報告し、方針を勝手に変更せず、依存しない実装を進めてください。実装上の通常の選択はあなたが行って構いません。

React/TypeScript/ViteとIndexedDBを用い、まずJSON取込→構造/意味検証→差分プレビュー→保存→全文表示→書出しを完成させてください。次に課題別評価、7観点、文章指数・音声指数、履歴、比較、ミスと強み、版選択、バックアップ/復元を実装します。正確な依存版は実装時に公式資料を確認して固定してください。

必須条件：

* RAW、Transcriptの各版、assessmentの各回、本人annotationを分離し、上書きしない。
* 原文を文法修正しない。AIと本人の全文、順序、根拠を参照できる。
* 未取得を0にしない。音源なしで発音・流暢さを推定しない。暫定live音声と保存音源の評価は混ぜない。
* Schemaだけでなく参照・引用・taxonomy・時間順・得点根拠も検証する。
* 再採点、Transcript修正、基準変更をそれぞれ独立に保持する。
* 同じファイルの再取込で件数を増やさない。同じIDの異内容は衝突として止める。別IDの重複候補は勝手に消さない。
* 指数の数式と欠測条件、語数、ミス集計、系列分離は03文書通りに実装する。38点方式・CSE変換・合格確率を追加しない。
* 初版は手動JSON取込と端末内分析。Voice/API/自動同期を勝手に追加しない。
* 実面接JSON・音源・公式や市販の問題画像を公開リポジトリへ入れない。合成fixtureで開発・テストする。
* iPhone相当の画面とPCで、コンパクトで落ち着いた情報設計にする。空状態・欠測・warning・エラーまで実装する。

既存リポジトリを確認して安全に組込み、仕様に合った段階で実装・テストを進めてください。契約の重要な分岐を確かめるテストを行い、実ブラウザで取込→詳細→比較→書出しを操作して確認してください。参照validatorが全意味制約を網羅すると仮定せず、03文書の本番検証条件を追加してください。

最後に、実装した動作、検証結果、残る制約、起動方法を報告してください。推測の採点や未実装の機能を完成と称さないでください。公開・push等はこのタスクで実際に与えられた権限に従ってください。
