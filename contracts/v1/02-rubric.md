# 学習用採点ルーブリック v1.0.0

これは本システム独自の診断尺度。英検公式の素点・CSE・合否・CEFRとは換算しない。得点の主目的は、次の練習を決め、同じ条件下で変化を確かめること。

## 実施規則

1. 問題・画像・使用するTranscript版・音源の利用範囲を先に固定する。
2. 各観点を独立に評価する。ミス1件につき1点減点という処理はしない。
3. 最も全体の遂行に合う整数アンカーを選び、原文・音声・イベントの根拠と理由を付ける。境界では低い方を自動選択せず、主要な遂行に近い方を選び、不確かさをconfidenceに記録する。
4. 不足する根拠はnullにする。0と未評価は別。引用・タイムスタンプは実在するものだけを使う。
5. 過去の評価は原則見せずに採点する。見えていたらblind_to_prior_scores=falseにする。
6. 教えた後の回答を、初回回答の点として採点しない。援助は条件に記録する。
7. 発音の聞き取りを推定語・修正版Transcriptで代用しない。話す速さだけで流暢さを判定しない。

## 観点別アンカー

| 観点 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| task_response：適合・内容 | 観測された回答が課題に応じない、または確認済み無回答 | 中心課題をほぼ満たさず、断片的・大きな取り違え | 主題には応じるが重要な欠落や説明不足がある | 課題に直接応じ、主要内容と必要な支えがほぼ伝わる | 課題に十分応じ、必要な情報・理由が明確で効果的 |
| organization：構成 | 発話はあるが内容の関係を辿れない | 断片の羅列で順序や関係が不明瞭 | 大筋は辿れるが飛躍・繰り返し・曖昧な参照が目立つ | 時系列・主張と理由・参照関係がおおむね明確 | 簡潔で一貫し、時系列・因果・説明の流れが自然 |
| grammar：文法・語法 | 十分なサンプルはあるが文の関係が継続的に崩れ理解困難 | 基本文法の誤りが頻発し意味理解に大きく影響 | 伝達は成立するが誤りが反復、使用範囲も限られる | 基本文法は安定し、必要な複文も使う。誤りは通常理解を妨げない | 課題に適した構文を柔軟かつ正確に用い、誤りは散発的 |
| vocabulary：語彙 | 十分なサンプルはあるが語選択が継続的に伝達を妨げる | 語の不足・誤用が多く、伝えたい意味が大きく失われる | 基本語で伝えられるが反復・不適切な語や言換えの限界がある | 課題に合う語を使い、必要時に言い換えて伝えられる | 適切で精度の高い語・自然な組合せ・言換えを柔軟に使う |
| intelligibility：明瞭さ | 音声は十分に聞けるが内容の大部分が理解不能 | 聞き取りの努力・推測が頻繁に必要 | 多くは理解できるが音・強勢・区切りの問題が時々妨げる | 全体に理解しやすく、ときどき問題があっても伝達は保たれる | 発音・強勢・区切りが明確で、意味を追う負担が小さい |
| fluency：流暢さ | 十分な試行があるが発話を繋げられず伝達がほぼ成立しない | 長い停止・再開始が多く、まとまった内容を維持しにくい | 間・修復が目立つが、短いまとまりで内容を伝えられる | 概ね適切なペースで続けられ、停止・修復は通常伝達を妨げない | 考える間を含め自然に継続し、修復も会話の流れに収まる |
| interaction：対話維持 | 十分な機会があるが応答・対話が成立しない | 指示・質問への対応が著しく難しく、対話が頻繁に途切れる | 対話は成立するが支援や不自然な再確認がたびたび必要 | 指示・質問に対応し、必要な聞き返しも自然で対話を維持 | 状況に応じて適切に確認・修復し、安定して意思疎通する |

## 課題別の読み替え

| 課題 | task_responseで見るもの | organizationで見るもの |
|---|---|---|
| narration | 4コマの主要事象、人物、変化、結果。画像にない説明の創作を中心にしない | 時系列・人物の参照・出来事の因果。開始文の使用は進行ルールとしても確認 |
| q1 | 指定人物・場面に即した考えと、それを支える状況理解 | 視点を保ち、考えや理由がつながる |
| q2 / q3 | 質問への直接の答え、関連する理由や具体化 | 主張と支えのつながり。単なるYes/Noの後に別の話題へ飛ばない |
| q4 | 社会的な問いを理解し、筋の通った意見を伝える | 意見・説明・例の関係。特定の政治的立場に加点しない |

理由の数・文数・語数の固定ノルマは採点しない。5語未満の英語はgrammar/vocabularyの評価サンプルとして不十分とするが、task_responseは質問と実際の答えに基づき評価できる。無回答はtask_responseだけ0、他はinsufficient_sample。短いが的確な応答と、情報不足な応答は課題に照らして区別する。

## 証拠の規則

| evidence_mode | 評価可能な範囲 | 表示 |
|---|---|---|
| text | 内容・構成・文法・語彙、文字から分かる対話行動 | Transcriptの種類と不確かさを添える |
| archived_audio | 採点時に実際にアクセスした保存音源 | 音声評価として再検証可能 |
| live_audio | その場では聞いたが保存音源を使っていない | 暫定の音声観察。保存音源由来と別系列 |
| event | 確認済み無回答・聞き返しなどの出来事 | 観測元を必ず参照 |
| none | 根拠なし | 未評価 |

intelligibility / fluencyはtextではscoredにしない。画像を必要とする内容評価で画像を読めない場合、task_responseはmissing_cardで未評価。grammar/vocabulary等の評価可能な観点は残せる。音声不良は受験者の発音不良と区別する。live_audioのconfidenceは最大mediumにする。

reason_code：missing_audio / missing_card / missing_question / missing_transcript / insufficient_sample / technical_failure / unsupported_modality / not_in_scope / uncertain_evidence。

## ミス・強みの扱い

* mistake：根拠のある誤り。severityはminor（局所的、理解を妨げない）、moderate（意味や内容を一部損なう）、major（中心の意味や課題成立を損なう）。件数から自動減点しない。
* strength：根拠のある成功。再現できる動作・表現として説明する。
* uncertain：ASR誤り等の可能性があり断定できないもの。ミス件数・弱点順位から除外。
* style_suggestion：元の英文でも成立する改善案。誤りとは扱わない。
* 自己修正済みの発話はresolved_in_turn=true。原文は保持し、修復に成功した強みも記録できる。未修正ミスの集計からは既定で除外する。

## 出力・集計

各課題の6観点＋セッションのinteractionを記録する。模擬の未評価も省略せずstatusで表す。部分練習は対象課題のみ。各観点にconfidence、reason、evidenceを付ける。主な強み、ミス、原意を保つ最小訂正版、自然な改善版、次回の重点最大3件を生成する。

文章指数は4観点、音声指数は2観点を各0〜100へ線形表示する。セッション重みはnarration .40、q1〜q4各.15。必要な観点が欠測なら全体指数はnull。4点の尺度は順序尺度であり、指数を精密な能力測定値として扱わず、整数表示を基本にする。interactionは合算しない。文・音声の指数を足した総合点は作らない。
